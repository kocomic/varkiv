# Varkiv 命名决定

状态：产品展示名已冻结；商标申请前仍需由专业机构完成目标地区的正式近似检索。

## 正式名称

- 标准拼写：`Varkiv`
- 品牌字标：`VARKIV`
- 建议读音：`VAR-kiv`；中文交流直接称“Varkiv”，不另造简称或音译名。
- 各语言界面保持同一拼写，只翻译描述性副标题。

`Varkiv` 是一个由 variant（变体）与 archive（归档）意象收束而来的新词，不把产品锁死在 ROM、模拟器或某一种前端上。它呼应同一游戏下原版、汉化版、改版和修订版并列存在的模型，也适合覆盖跨平台系列、整合包和存档同步。

## 选择依据

- 单个词，避免机械拼接 `ROM`、`Emu`、`Retro` 等功能前后缀。
- 英文拼写和口头转述稳定，不依赖中文简称。
- 没有把产品误导成模拟器、游戏平台或在线刮削服务。
- 适合硬朗、漫画编辑感的字标与图形系统。
- 冻结前的公开网页、代码托管、应用目录与软件类别初筛未发现直接同名的游戏库产品；该结果只降低冲突风险，不构成法律意见或可注册保证。

## 技术命名

正式命名同时覆盖产品层和技术层，不保留旧工程代号：

- Go 模块、二进制与 npm 包名：`varkiv`；
- 环境变量：`VARKIV_*`；
- Android application ID：`org.varkiv.agent`；
- API 兼容头、清单格式、配置目录、Compose 服务与卷统一使用 `varkiv`。

稳定 API 之前不为旧工程代号保留兼容别名。数据库 schema 和领域资源仍按职责命名，不把品牌嵌入无关业务概念。

## 视觉资产

图形标志使用层叠的棱角化字母 `V`：多条版本路径向下聚合但保持各自边界，对应原版、汉化版和改版在展示上归组、在文件与存档上独立。荧光绿用于识别面，紫色错位阴影表达漫画印刷层次。详细规范见 [BRAND.md](BRAND.md)。
